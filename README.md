# 寶步宇宙王國 · baobuverse-kingdom

兩個 app，一套資料，一個世界觀。

- **baobu-treasury** 國庫 — 記帳與金流
- **baobu-nest-diary** 窩日記 — 生活記錄

## 為什麼要做這個

因為生活裡有太多事情記不住：這個月到底花去哪、那部劇看到第幾集、
冷氣上次清潔是什麼時候、那張優惠券還剩幾天、上次大爆買是什麼時候。
這些事分散在腦袋、對話紀錄和一堆互不相通的 app 裡。

所以我們蓋了這個。核心只有一句話：**記一個地方，其他地方跟著動。**

看了一集劇、做了一次家務、買了一樣東西——只記一次，
當天的日記自動就有了；花的錢自動進到國庫；
誰幫誰代墊的錢，自動記進兩個人之間的往來帳。

做得到這件事，是因為底層只有一種東西：**一次動作寫一則事件，
事件可以同時掛好幾個效果。** 買一台空氣清淨機不是三件事，
是一件事的三個面向——一筆錢、一件物品、當天日記的一行。

## 兩條不可妥協的規則

1. **轉帳不是支出。** 錢在自己的帳戶之間搬動，淨資產不變。
   加值悠遊卡是轉帳，悠遊卡搭捷運才是支出。
2. **日記不是一張表。** 日記是當天所有事件的查詢結果。

## 隱私

同一套 Firebase，兩個人各自的紀錄互相看不到。
共享的只有跟兩個人都有關的錢（幫對方、幫共、往來帳、還款）、家務，以及標記為「一起看」的劇。

## 資料放在哪

**新開一個免費的 Firebase 專案**，國庫和窩日記一起用：同一套登入、同一個資料庫，各自一個網址。
國王日記留在它自己的 `baobu-app` 專案，完全不碰——它已經運行很久，不能被新專案碰到。
（2026-10-30 改：原本打算在 `baobu-app` 另開一個資料庫，但那要升級付費，也跟國王日記擠在同一個專案裡。）
