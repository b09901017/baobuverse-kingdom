## 候選（先對 lessons.md 已經有的，重複的不加；**原因沒確認的不寫成原因**）

- 這個環境寫反斜線出錯：段 8 以為是「heredoc 把 `\\` 變成 `\`」，但帶引號的 `<<'EOF'` 在 bash 不處理反斜線，比較可能是 Python 一般字串把 `\b` 解成退格、或工具傳指令時轉義。
  `$(…)` 裡有 `$'…'` 報錯在 bash 語法上合法，可能也是工具層。寫之前先重現確認；確認不了就把重點寫成「寫反斜線用 Write／Edit；報錯的指令先查狀態再重來」
- Git Bash 的 `awk` 把 CRLF 變 LF → 改有 CRLF 的檔用 Edit 或讀寫 bytes
- mod 測試的 `$` 不能直接呼叫模組裡的函式、`$.env.get` 要寫字面上的名字 → 要測的函式抽出去吃一個小的 `Io`
- 比對私人值時錯誤訊息或 diff 會把值印進對話（段 7 第 5 條、主控兩次）→ 用 spawnSync、不要把值放進指令字串；查私人檔只看檔名、`--numstat`、挑過的行
- Windows 深路徑 clone 失敗、錯誤訊息印出檔名 → 短路徑＋`core.longpaths=true`、錯誤導到檔案只算行數
