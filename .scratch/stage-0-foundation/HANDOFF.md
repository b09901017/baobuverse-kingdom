## 每一段共同的規矩

- 先讀 `CLAUDE.md`、`docs/agents/lessons.md`、`../spec.md`、自己那幾支 issue 的「動工前先讀」。
- 動工前 `git fetch`；分支落後 `main` 就 rebase。一支一個 commit；做完改 `Status: done`、寫「做完時留下的」、跑驗證指令（02 做完之後有）。
- 改一個函式或一段畫面上的字之前，用 `grep` 找出所有呼叫端與畫面上出現的地方。
- **中途發現的事不岔出去修**：記進下面「中途發現」（哪裡、什麼情境會錯、建議），繼續做原本的；段末一次問。使用者說要修的，修之前再 grep 牽連，照一支 issue 的規矩做。
- 同時最多兩個 subagent。
- 要使用者決定的：一次一題、白話、附建議（使用者可以只回「照建議」）。能查到、能自己判斷的不問。給使用者看的回覆用繁體中文。
- **絕對不碰 `baobu-app`**（國王日記的專案）：不寫、不部署、不改設定。只讀也只在 issue 叫你讀的時候。
- 公開 repo：不寫 email、帳號、餘額、金鑰；網頁設定（apiKey 那一組）可以。
- 指令或腳本裡有 firebase、`rm`、`git push`、`baobu-app` 這類字會被 guard 跳框（lessons 第七條，2026-10-30 改成不拆字）：照常寫，**不要拆字躲檢查**；跳框前先跟使用者說一聲是什麼。
- **主控會開下一段：不要自己開 session，也不要存 limit-guard 的開場 JSON。**
- 段開始時：`list_sections` 找上面那個組名，一模一樣就 `move_sessions` 把自己放進去；做完把對話標題改成白話的結果（開 PR 的對話開頭寫 `PR #N · `）。

## 中途發現

### 段一

- **Firebase CLI 已經登入擁有 `baobu-app` 的帳號**（issue 01 原本寫沒登入），而且這台電腦沒有全域的 `firebase`，都用 `npx -y firebase-tools@latest`。
  情境：05、06 任何 firebase 指令沒帶 `--project`、又沒有 `.firebaserc` 時，CLI 可能落到別的專案。建議：05 一開始就建 `.firebaserc`（只寫 `baobu-kingdom`），每個指令也明寫 `--project baobu-kingdom`；`firebase-tools` 可以考慮裝成根目錄的 devDependency 寫死版本。
- **Windows 深路徑讓 pnpm 12 跑不起來**：在 scratchpad 的深路徑 clone 跑 `pnpm verify`，寫 `node_modules/.pnpm-task-run-state-v1/...` 時報「系統找不到指定的路徑」（超過 260 字元）。乾淨 clone 要放短路徑（段一用 `%TEMP%\bkv`，跑完刪了）。跟 lessons 第五條是同一種坑，段六審查時可以考慮補進 lessons。
- **gcloud 也看得到新專案**：段一用 gcloud 的權杖只讀查了帳單、Google 登入、規則。之後要查「Google 登入有沒有開」這種 firebase CLI 查不到的，可以照 01 的做法。
- **資料庫的刪除保護是關的**（`DELETE_PROTECTION_DISABLED`）：上線前一鍵重置需要它關著；上線、拿掉一鍵重置時可以順便打開。不用現在決定。

### 段二

- **Firestore 的讀取量會跟著事件數長**（ADR 0001「後果」）：監聽斷線超過 30 分鐘再連上會重新計費整個查詢，免費方案每天 5 萬次，估計一年後就接近。
  情境：正式上線一年左右，每天打開十次。建議：05 照 ADR 先用一般監聽、文件從第一天就有 `updatedAt` 與刪除標記；最晚正式上線前換成增量同步（只讀比上次新的、其他從本機快取讀），資料不用改。放進之後某一輪的 issue。
- **第一份成員文件怎麼建**：規則不能讓任何登入的人自己加進王國，但步第一次登入時 `kingdoms/{k}/members/{uid}` 還不存在。05 要決定（例如王國文件不存在時才允許建、建的人寫成步；或用 CLI 先建好）。
- `apps/treasury/src/App.tsx` 還在用 `coreReady`（02 的接線檢查），段二留著沒動；05 換掉驗證頁時可以一起拿掉。
- 03 原本寫事件有「擁有者」與「記的人」兩個欄位；段二併成一個 `recordedBy`（只有記的人能改，看得到的是參與者），理由在 ADR 0001 第 8 點。
