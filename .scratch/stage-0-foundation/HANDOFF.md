## 每一段共同的規矩

- 先讀 `CLAUDE.md`、`docs/agents/lessons.md`、`../spec.md`、自己那幾支 issue 的「動工前先讀」。
- 動工前 `git fetch`；分支落後 `main` 就 rebase。一支一個 commit；做完改 `Status: done`、寫「做完時留下的」、跑驗證指令（02 做完之後有）。
- 改一個函式或一段畫面上的字之前，用 `grep` 找出所有呼叫端與畫面上出現的地方。
- **中途發現的事不岔出去修**：記進下面「中途發現」（哪裡、什麼情境會錯、建議），繼續做原本的；段末一次問。使用者說要修的，修之前再 grep 牽連，照一支 issue 的規矩做。
- 同時最多兩個 subagent。
- 要使用者決定的：一次一題、白話、附建議（使用者可以只回「照建議」）。能查到、能自己判斷的不問。給使用者看的回覆用繁體中文。
- **絕對不碰 `baobu-app`**（國王日記的專案）：不寫、不部署、不改設定。只讀也只在 issue 叫你讀的時候。
- 公開 repo：不寫 email、帳號、餘額、金鑰；網頁設定（apiKey 那一組）可以。
- 指令或腳本裡有 firebase、`rm`、`git push`、`baobu-app` 這類字會被 guard 跳框（lessons 第七條，2026-10-30 改成不拆字）：照常寫，**不要拆字躲檢查**；跳框前先跟使用者說一聲是什麼。
- **主控會開下一段：不要自己開 session，也不要存 limit-guard 的開場 JSON。**
- 段開始時：`list_sections` 找上面那個組名，一模一樣就 `move_sessions` 把自己放進去；做完把對話標題改成白話的結果（開 PR 的對話開頭寫 `PR #N · `）。

## 中途發現

### 段一

- **Firebase CLI 已經登入擁有 `baobu-app` 的帳號**（issue 01 原本寫沒登入），而且這台電腦沒有全域的 `firebase`，都用 `npx -y firebase-tools@latest`。
  情境：05、06 任何 firebase 指令沒帶 `--project`、又沒有 `.firebaserc` 時，CLI 可能落到別的專案。建議：05 一開始就建 `.firebaserc`（只寫 `baobu-kingdom`），每個指令也明寫 `--project baobu-kingdom`；`firebase-tools` 可以考慮裝成根目錄的 devDependency 寫死版本。
- **Windows 深路徑讓 pnpm 12 跑不起來**：在 scratchpad 的深路徑 clone 跑 `pnpm verify`，寫 `node_modules/.pnpm-task-run-state-v1/...` 時報「系統找不到指定的路徑」（超過 260 字元）。乾淨 clone 要放短路徑（段一用 `%TEMP%\bkv`，跑完刪了）。跟 lessons 第五條是同一種坑，段六審查時可以考慮補進 lessons。
- **gcloud 也看得到新專案**：段一用 gcloud 的權杖只讀查了帳單、Google 登入、規則。之後要查「Google 登入有沒有開」這種 firebase CLI 查不到的，可以照 01 的做法。
- **資料庫的刪除保護是關的**（`DELETE_PROTECTION_DISABLED`）：上線前一鍵重置需要它關著；上線、拿掉一鍵重置時可以順便打開。不用現在決定。

### 段二

- **Firestore 的讀取量會跟著事件數長**（ADR 0001「後果」）：監聽斷線超過 30 分鐘再連上會重新計費整個查詢，免費方案每天 5 萬次，估計一年後就接近。
  情境：正式上線一年左右，每天打開十次。建議：05 照 ADR 先用一般監聽、文件從第一天就有 `updatedAt` 與刪除標記；最晚正式上線前換成增量同步（只讀比上次新的、其他從本機快取讀），資料不用改。放進之後某一輪的 issue。
- **第一份成員文件怎麼建**：規則不能讓任何登入的人自己加進王國，但步第一次登入時 `kingdoms/{k}/members/{uid}` 還不存在。05 要決定（例如王國文件不存在時才允許建、建的人寫成步；或用 CLI 先建好）。
- `apps/treasury/src/App.tsx` 還在用 `coreReady`（02 的接線檢查），段二留著沒動；05 換掉驗證頁時可以一起拿掉。
- 03 原本寫事件有「擁有者」與「記的人」兩個欄位；段二併成一個 `recordedBy`（只有記的人能改，看得到的是參與者），理由在 ADR 0001 第 8 點。

### 段三

- **步的帳本看不到寶媽卡**（帳戶只有主人讀得到）：寶刷寶媽卡「幫共付」時，步的帳本不知道那是寶媽卡，會把那一筆算成**寶的我付的**。
  步自己的數字（我用的、往來帳）不受影響；只有「在步的帳本看寶的數字」或「所有人加起來」會多算。
  情境：階段 6 做「看對方的數字」或兩人合計的畫面時。建議：那時讓成員讀得到 `paidByOthers` 的帳戶（至少知道它是寶媽卡），或畫面永遠從本人的帳本看本人的數字。
- **退款的行沒有指回原本那一項**：`Line` 的 `event`、`entry` 是退款那一則，沒有 `item`（`item` 是那一筆裡的品項，退款那一筆沒有品項）。
  情境：階段 1 做「原本那筆上的退款註記」時，要從事件找 `refund.target`。建議：真的要從 `lines` 拿，再在 `Line` 加一個 `refundOf`（只改 core，資料不用動）。
- **記的人看不到對方的帳戶**：`validateEvent` 要求參考的帳戶都找得到，所以寶記「寶直接給步」不能填步的收錢帳戶（`cash.into`），記「寶還步」不能填步收錢的帳戶。
  情境：階段 6 的記帳畫面。建議：那一格讓記的人空著（形狀本來就允許）；收錢的人的帳戶餘額怎麼補，階段 6 再設計（例如像「有疑問」那樣，讓收錢的人只改自己那一格）。
  空著的話收錢的人的帳戶不會變，下次對帳會多出一段對帳差額。
- **比例只能是正整數**（`weights-invalid`，`ProblemCode` 的註解改了）：金額不准用浮點數，`捨去(金額 × 份數 ÷ 總份數)` 才全程整數。情境：進階的改比例畫面。建議：輸入框只收整數（6:4、55:45）。
- **Bash 工具的 heredoc 裡有 JS 樣板字串**（反引號＋`${…}`）時，整段報 `unexpected EOF while looking for matching`、什麼都沒跑（照 lessons 第四條查過）。改成先寫成檔再跑就好。原因沒查；跟 lessons 第二條是同一類（指令交給 bash 之前被改過），段六可以考慮併進 lessons。

### 段四

- **一鍵重置（06）不要刪王國文件與成員文件**：第一份成員文件是「王國文件還不存在時，第一個登入的人按建立王國」（05「做完時留下的」）。
  情境：06 重置時把 `kingdoms/baobu` 整個刪掉，到步再按「建立王國」之前，任何登入的人都可以先按、變成步。建議：重置只清資料（事件、帳戶、罐子、標籤…），留 `kingdoms/baobu` 與 `members`；
  或重置完馬上自己按。同一個空窗：06 部署 Hosting 之後網址是公開的，但現在步已經建好王國，不受影響。
- **任何登入的人都可以建一個別的王國**（`kingdoms/{別的 ID}`，自己當建立者）：寫不到我們的王國、讀不到我們的資料，只會用掉免費額度。
  情境：有人知道這個專案、用 Google 登入亂建。建議：正式上線前，看要不要把王國 ID 寫死在規則裡（`k == 'baobu'`），或只讓指定的帳號建。
- **web.app 上的 redirect 登入可能要在 Google Cloud 加重新導向網址**：Google 登入的 OAuth 用戶端預設只有 `baobu-kingdom.firebaseapp.com/__/auth/handler`。
  情境：06 部署後在 `baobu-kingdom.web.app` 按登入，跳 `redirect_uri_mismatch`。建議：06 驗登入時先看；有錯就在 Google Cloud 主控台的 OAuth 用戶端加 `https://baobu-kingdom.web.app/__/auth/handler`（要使用者點）。
- **事件的參與者是記的人寫的，規則驗不了對不對**（規則不能跑 `participantsOf`）：記的人只要自己在裡面，可以多寫或少寫別人。
  情境：程式有 bug、或之後別的 app 寫事件沒用 `store.ts`，共付的事件寶看不到。建議：所有寫事件的地方都經過 `store.ts` 的 `save`；階段 6 可以考慮加一支檢查（讀全部事件、重算參與者、比對）。
- **測試小幫手空過**：`@firebase/rules-unit-testing` 的 `withSecurityRulesDisabled` 不回傳回呼的結果，「讀伺服器上的文件」的小幫手一開始永遠拿到 `undefined`，
  「沒存進去」那支因此空過（同一輪另外兩支變紅才發現）。規則測試第一次就 26 支全過，所以另外放寬規則確認會變紅。段六可以考慮補進 lessons：「全過的測試，先確認它會紅」。
- **Claude 的內建瀏覽器開不了 popup**（popup 會蓋掉原本的分頁、登入結果回不來），驗登入要用 redirect；模擬器要用 `localhost` 不能用 `127.0.0.1`。已寫進 05「做完時留下的」，也可以補進 `docs/env-notes.md`。
- **Windows 上 git 提示 LF 會換成 CRLF**（這一段新加的檔都是 LF）：只是提示，沒有改檔；如果之後 diff 出現整份換行不同，查 `core.autocrlf`。
