## 要有測試的規則（數字照 plan.md 與對話裡的例子）

| 情況 | 我付的 | 我用的 | 寵對方 | 被寵 | 往來帳（對方欠我） | 我的罐子扣 |
|---|---|---|---|---|---|---|
| 幫自己付 5,000 | 5,000 | 5,000 | | | 0 | 5,000 |
| 幫對方付 3,000 | 3,000 | | | | +3,000 | 0 |
| 對方幫我付 1,200 | | 1,200 | | | −1,200 | 1,200 |
| 幫共付 2,000（5:5） | 2,000 | 1,000 | | | +1,000 | 1,000 |
| 寵對方 500 | 500 | | 500 | | 0 | 500 |
| 對方幫共付 2,000（5:5） | | 1,000 | | | −1,000 | 1,000 |
| 對方買東西寵我 300 | | | | 300 | 0 | 0 |
| 對方直接給我 1,000 寵我 | | | | 1,000 | 0 | 0（同時算收入 1,000） |
| 對方還我 5,000 | | | | | −5,000 | 0（也不是收入） |
| 郵局轉國泰 10,000 | | | | | 0 | 0（兩個帳戶一減一加） |

再加：

- 恆等式：我付的＝我用的＋寵對方＋往來帳因支出的變化（對方欠我為正，可以是負的；還款不算）。用上表每一列各驗一次。
- 刷信用卡 1,000：信用卡欠款 +1,000、算支出；用銀行繳卡費 1,000 是轉帳，不再算支出。
- 寶媽卡：刷 3,000 → 寶媽卡上寶媽幫出的 +3,000、算寶的支出、寶的淨資產不動（寶媽卡不算進淨資產）。
  寶還寶媽 5,000 是**還款**（使用者 2026-10-30 定的）：寶的銀行 −5,000、寶媽卡 −5,000、不算支出也不算收入、寶的淨資產 −5,000。
- 跨行轉帳 1,000、手續費 15：同一則事件，轉帳 1,000＋支出 15。
- 對帳：實際 1,050、算出 1,200 → 對帳差額 −150，不算支出也不算收入；之後的餘額是 1,050。第一次對帳就是初始餘額。
- 退款：原本那一項（日常、標籤「家樂福」）820 退 95 → 日常與「家樂福」的支出各少 95，不算收入。
- 品項：整筆 820、標籤「家樂福」，品項 95（吃吃）＋725（居家）→「家樂福」820、「吃吃」95、「居家」725；品項加總不等於整筆時拒絕。
- 進階：820 裡 650 那一項改成幫對方付 → 我用的 170、往來帳 +650；幫共付 1,000 用 6:4（我 6）→ 我用的 600、往來帳 +400。
- 篩選：十月與十一月各一筆日常 100，查十月的日常 → 100；查標籤「家樂福」只算有那個標籤的品項。
