**不做**（各有自己的階段）：標籤三幫手、名稱自動補完、拆成品項的畫面、語音、長按圖示、APK（階段 2）；標籤空著的集中提醒（階段 2）；統計、視角、按月攤、待收（階段 3）；畫風與首頁（階段 4）；固定花費、收件匣（階段 5）；往來帳畫面、還款、寵對方、有疑問（階段 6）。

## 談定的

### 使用者選的

| 題目 | 結果 |
|---|---|
| 誰出選寶時能不能選寶的帳戶 | 可以：列出寶的帳戶（含寶媽卡），也可以留空表示「不知道」 |
| 對方的帳戶看得到什麼 | 名字、種類看得到；餘額看不到（卡片牆只顯示自己的帳戶）；備註只有自己看得到 |
| 寶的帳戶誰建 | 寶搬過來之前，步可以幫寶建 |
| 標籤 | 預設一批（`.local/kingdom-accounts.md`）；都不帶預設罐子 |

**推翻了什麼**：階段 0 的「帳戶只有主人讀得到」（`firestore.rules` 的 accounts、ADR 0001「Firestore 上怎麼放」那一列）。那是 AI 的設計，不是使用者定的；使用者定過的只有事件（「幫自己付」的對方看不到），這條不變。

**為什麼非改不可**：寶媽卡是用「選帳戶」表示的，選不到就記不了「刷寶媽卡」，那筆會被算成寶自己付的（寶的我付的灌水、寶媽卡的欠款對不上）；
刷寶的信用卡選不到的話，寶的卡片餘額不動，寶下次對帳會多一段對帳差額，而寶又不能改步記的那筆。

**順便解決**：階段 0 HANDOFF「中途發現 · 段三」的「步的帳本看不到寶媽卡」「記的人看不到對方的帳戶（還款、直接給錢填不了收錢帳戶）」。

### 主控定的（跟使用者說過、使用者沒有反對）

| 情況 | 決定 |
|---|---|
| 記錯一筆要能改（階段表沒寫，但不能改就沒辦法測） | 加流水頁，點一筆可以改、可以刪（刪除只做標記）。有退款的那筆不能刪，金額不能改到比已退的少，日期不能改到退款之後 |
| 帳戶資料不能進公開 repo，也不能打包進網站；一鍵重置又會把帳戶刪掉 | 資料放 `.local/` 的一個檔，在設定頁選檔匯入一次，存進只有本人讀得到的 Firestore 文件；重置不刪這份，重置後按一下「套用預設」就回來 |
| 加密貨幣的各自投入怎麼記 | 不用加新種類：匯入時各記一則轉帳（步、寶各從自己的帳戶 → 共有帳戶），排在第一次對帳之前，第一次對帳的初始餘額會把那段錢吸收掉，帳戶餘額與淨資產都對。投入的轉帳與步的初始餘額要分開成不同事件：共有帳戶的事件寶看得到，步的實際餘額不能在裡面 |
| 太久沒對帳的門檻 | 超過 30 天寫天數；投資帳戶不顯示 |
| 標籤太多不好選 | 記帳畫面只先顯示最常用的幾個，其他收在「更多」；還沒有使用紀錄時照預設的順序 |

### 主控定的（沒特別說，段照做）

| 情況 | 決定 | 理由 |
|---|---|---|
| 誰出的預設 | 跟上一次一樣；帳戶是那個人上次用的（第一次是自己的現金帳戶） | plan.md 定了帳戶、幫誰都是上一次；帳戶要跟誰出對得上 |
| 罐子選單 | 幫步：步的罐子；幫寶：寶的罐子；幫共：兩個人都有的罐子。換了幫誰、原本的罐子不在清單裡就回到日常 | 共付的品項每個人那一份算在同一個罐子（ADR 0001 第 3 點） |
| 「誰收」 | 收入也可以選誰收（預設自己），帳戶跟著那個人 | plan.md「誰記都可以」 |
| 轉帳的帳戶 | 列步的、共有的與寶的；選了來源，目的只列同一個人或共有的 | 「誰記都可以」；core 的 `transfer-owners` 本來就會擋 |
| 打開 app 第一頁 | 暫時是帳戶頁 | 「主畫面打開第一眼要看到什麼」還沒決定，階段 4 才定；這不算決定 |
| 退款的行指回原本那一項 | 不改 `Line`，core 給一個從事件查的函式 | 註記是看事件，不是看數字 |
| E2E | 這一輪不裝 `@playwright/test`；每一段用模擬器在內建瀏覽器走過 | 階段 4 會整個換畫面，現在寫的選取器之後全要重寫。算錢與組事件的邏輯抽成純函式寫測試 |
