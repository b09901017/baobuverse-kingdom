# 06 轉帳、對帳（差額另列）、退款註記

Status: done
Blocked by: 02、05

動工前先讀：`../spec.md`；README「兩條不可妥協的規則」；GLOSSARY「轉帳」「對帳」「對帳差額」「退款」；`packages/core/src/ledger.ts` 的 `transfer`、`mover`、`reconcile`、`refund`；02、04、05「做完時留下的」。

## 使用者要的

「**轉帳不是支出。** 錢在自己的帳戶之間搬動，淨資產不變。加值悠遊卡是轉帳，悠遊卡搭捷運才是支出。」（README）
「**對帳**：看著實際餘額輸入，跟算出來的比；差額叫對帳差額，另外列。每個帳戶的第一次對帳就是初始餘額。」
「**退款**：在原來那筆上作註記。」
「**加密貨幣**：……只在意各自投入多少、之後拿出來多少，不在意市值。」
階段表：「轉帳、對帳（差額另列）、退款註記」。

## 為什麼會這樣

core 都算好了：`Transfer`（`mover` 決定共有帳戶那邊算誰的）、`Reconciliation`（第一次是初始餘額、之後差額進 `reconcileDiff`）、`Refund`（沖回原本那一項）。02 補了退款的查法與約束。這一支是畫面。

## 做法

1. 轉帳：記一筆的第三個分頁。金額、從、到、日期、時間、名稱（可空）。帳戶選單照 `../spec.md`；選了來源，目的只列同一個人或共有的；不能選同一個；寶媽卡不出現（那是還款，階段 6）。
2. 對帳：帳戶詳情的按鈕（投資帳戶沒有）。輸入實際餘額（信用卡輸入欠多少、存成負數），即時顯示「算出來 X、差 Y」；第一次寫「這是初始餘額」。存成一則事件。差 0 也要存，「N 天沒對帳」才會歸零。對帳可以改、刪（跟 05 同一套）。
3. 對帳差額另列：帳戶頁下面一區（或帳戶詳情）列出自己的每一筆差額與合計（查詢帶 `person: me`），不混進收入、支出。流水頁也列，但樣子不同、看得出它不是支出。
4. 退款：支出的詳情有「退款」：金額（預設還沒退的全部、不能超過）、日期、時間、退回哪個帳戶（預設原本那個；清單只列那筆誰出的人的帳戶，不含投資）。存成一則新事件（`title` 帶原本的名稱）。
   原本那筆在流水頁和詳情上註記「已退 X」與每一筆的日期（`refundsOf`），退款自己那一列也指得回原本那筆。不算收入。退款可以改、刪。
5. 流水頁接上這三種；刪退款後註記消失。

## 判準

- 轉帳後淨資產變了嗎？（不能變）我用的、我付的、收入有動嗎？
- 加值悠遊卡 500、再搭捷運 30：卡片餘額對嗎？我用的是 30 嗎？
- 繳卡費（銀行 → 信用卡）：銀行少、欠的少、淨資產不變？
- 步轉 1,000 進共有帳戶：共有帳戶裡是步投入多 1,000？寶的那份沒動？步的淨資產不變？從共有帳戶轉回步的帳戶呢？
- 步幫寶記「寶的銀行 → 寶的信用卡」：步的數字有動嗎？（不該）
- 轉帳選單會出現「步的帳戶 → 寶的帳戶」嗎？（不該，那是還款）
- 第一次對帳算對帳差額嗎？（不該）第二次對帳差 -200：對帳差額列出 -200、餘額變成實際的、不算支出？
- 信用卡對帳輸入 3,000，存的是 -3,000？差額方向對嗎？
- 補記一筆比對帳早的支出：對帳差額跟著變（這是對的，ADR 0001），帳戶頁的差額數字有馬上更新嗎？
- 刪掉第一次對帳：下一次對帳變成初始餘額，差額不見，餘額還對嗎？
- 差 0 的對帳存得進去、天數歸零，而且不多一行差額？
- 退款後：原本那筆的罐子、標籤的我用的變少？餘額回到帳戶？收入沒變？（用 `book.total` 寫測試）
- 共付那筆退款：步、寶各沖回多少？零頭算誰出？
- 退超過還沒退的：畫面擋得住嗎？
- 手機寬度開來走一次、截圖。

**補定的**（issue 沒寫，照之前說的判斷）

| 情況 | 決定 | 理由 |
|---|---|---|
| 信用卡多繳（銀行要還我）怎麼對帳 | 表單多一個勾選，勾了才存成正的；不勾輸入都算欠多少 | 原本的 `parseActual` 不收負數，多繳的卡會對不了帳；又不能讓人把「欠 3,000」打成負號存反 |
| 封存的帳戶能不能對帳 | 可以（主人有我、不是投資就有按鈕） | 收掉的帳戶還有零頭時，要能對到 0，淨資產才對 |
| 轉帳的預設 | 跟我上一次轉帳一樣；第一次來源是自己的現金、目的自己選；套用預設寫的投入不算 | `plan.md`：帳戶預設上次用的 |
| 換匯的轉帳（`amountIn`） | 表單打不開 | 跟 05 拆過品項的同一個理由：表達不了就不要假裝改得了 |
| 對帳事件的名稱 | 新的存「對帳」；流水頁的「初始餘額／對帳」看先後，不看存的字 | 刪掉第一次之後，下一次要變成初始餘額 |
| 別人記的那筆支出 | 看得到退款註記，也按得到「退款」 | 退款是一則新事件，不是改那一筆；別人幫我記的那筆，退回來的是我 |
| 拆過品項的那筆 | 沒有「退款」 | 階段 1 沒有拆品項的畫面，選不了退哪一項；階段 2 接 |
| 原本那筆不知道帳戶 | 退款選單多「不知道（不動任何帳戶）」；原本有帳戶就沒有這一項 | 沒寫帳戶的退款會回到原本的帳戶，所以「不知道」只有原本也不知道時才是真的 |
| 帳戶頁的對帳差額 | 摺起來，摘要直接寫合計；沒有差額時整區不出現 | 數字一眼看得到；每一筆點開才列，平常不佔位 |
