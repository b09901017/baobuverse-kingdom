# 05 記支出與收入、流水頁、改與刪

Status: todo
Blocked by: 02、04

動工前先讀：`../spec.md`「主控定的」；`docs/plan.md`「記一筆」「記一筆的細節」；GLOSSARY「誰出」「幫誰」「我用的」「我付的」「收入」；`store.ts`；02、04「做完時留下的」。

## 使用者要的

「**快速記一筆**：必填的只有金額。可以選罐子、標籤，記一個簡單的名稱（怕之後補記時忘記是什麼）。」
「**平常只記誰出、幫誰**：「我覺得只要記誰(寶步)幫誰(寶步共)出就好……要不要還這個不用填，預設都是要還」」
「**誰記都可以，一筆只記一次**」
「**單獨選的只有帳戶、罐子、誰出、幫誰，其他都是標籤。** 標籤可以多選，想多記一點資訊時就多點幾個；怕標籤太多不好選。」
「**預設值**：帳戶預設上次用的（第一次預設現金）、時間預設現在、幫誰預設跟上一次一樣、要還；沒選罐子算日常」
「**收入**：只記金額、進哪個帳戶、標籤（薪水、獎金、紅包、回饋…），不分罐子」
「**幫朋友先付（朋友之後還我）、寶媽這類平常用不到的，不要出現在平常記帳的畫面**」「**不要讓任何數字被灌水。**」

## 為什麼會這樣

core 的 `Expense`、`Income`、`validateEvent`、`save` 都有了（階段 0），這一支是把畫面接上去。階段 1 沒有拆品項的畫面：一筆一項，事件的 `title` 和品項的 `name` 一樣。

## 做法

1. 純函式（寫測試）：表單的值 → `Event`（`buildExpense`、`buildIncome`）；上一筆的預設（誰出、帳戶、幫誰）；帳戶選單；罐子選單（`../spec.md`）；標籤排序（用過的次數，還沒有就照 prefs 的順序）。
2. 記一筆：分「支出」「收入」（「轉帳」06 接）。金額整數、必填。支出：名稱、誰出（步／寶）、帳戶（可以留空＝不知道）、幫誰（步／寶／共）、罐子、標籤、日期（預設今天）、時間（預設現在）。收入：金額、名稱、誰收、帳戶、標籤、日期、時間。
   帳戶選單：支出列誰出那個人沒封存的帳戶，不含投資（含寶媽卡）；收入列誰收那個人沒封存的帳戶，不含投資、不含寶媽卡。投資帳戶轉進轉出都是轉帳（GLOSSARY），core 不一定擋得到（步自己的投資帳戶付支出存得進去），所以選單要排除。
   `plan.md` 沒定的細節照 `../spec.md`。沒有「日常」罐子時（還沒套用預設）同一批建一個，ID 用 03 定的常數，主人步和寶。
   標籤：最常用的先顯示，「更多」展開，可以當場加新標籤（押金就是這樣用）。
3. 流水頁：依日期倒排，同一天一組。每一列：名稱（沒有名稱時用標籤或種類）、金額與方向、帳戶、「誰出 → 幫誰」（幫自己付的不用寫）。支出、收入先有；轉帳、對帳、退款 06 接。可以依帳戶篩（從卡片點進來）。
4. 改與刪：點一列打開同一個表單。只有記的人能改（現在只有步）。存的時候保留事件的 `id`、`recordedBy`、`recordedAt`（規則不讓改），以及一筆、品項的 ID（退款指著它們）。選單除了平常的，還要含這一筆現在用的帳戶、罐子、標籤（就算封存了），不然表單變空、存成「不知道」，餘額會默默變。有退款的那筆，誰出、幫誰照 02 鎖住。刪：`store.ts` 加標記刪除（`deleted: true`，`participants` 留著、`updatedAt` 更新），先問一次。有退款的照 02 擋，畫面用白話說為什麼。
5. `validateEvent` 的 `ProblemCode` 換成白話（不要把代碼丟到畫面）。

## 判準

- 只填金額就能存嗎？存完餘額、淨資產馬上對嗎？離線時呢？（畫面不等 `written`）
- 步記「寶付、寶媽卡、幫寶、500」：步的帳戶動了嗎？寶的我付的多算嗎？
- 步記「步付、幫共、1,001」：步的我用的 501、寶的我用的 500（零頭算誰出）嗎？流水頁那一列有寫「步 → 共」嗎？
- 支出、收入的帳戶選單會出現投資帳戶嗎？收入選單會出現寶媽卡嗎？
- 用封存的帳戶記過的一筆，打開改名稱再存：帳戶還是原本那個、餘額沒變？（`buildExpense` 的測試）改完 entry、item 的 ID 沒變？
- 換誰出之後，帳戶會不會留著另一個人的？（`account-not-payers` 不該跳到使用者臉上）
- 換幫誰之後，罐子還在清單裡嗎？不在的話回到日常了嗎？
- 收入有罐子嗎？（應該沒有）收入會出現在支出的任何加總嗎？
- 改一筆之後，`id`、`recordedAt` 沒變？改完還是一則事件，不是多一則？
- 刪掉的那筆在所有數字、流水頁、「上一筆的預設」裡都不見了？再重新整理也不見？
- 金額打 `0`、負數、小數、空白時怎麼樣？（擋住，字講清楚）
- 平常的畫面看得到「不用還」「待收」「比例」這些進階嗎？（不該）
- 用了 3 次的標籤排到「吃吃」前面了嗎？第一次用時順序是預設的嗎？
- 手機寬度開來走一次、截圖。
