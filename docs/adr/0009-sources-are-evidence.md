# 同一筆消費的多個來源是同一則事件的證據

刷卡通知、載具發票、拍照的發票、信用卡帳單 CSV 常常描述同一筆消費。若每個來源各寫一則事件，
一筆 350 元會記成三筆。所以所有自動來源都只產生收件匣草稿：先到的建立草稿，
後到的若金額相同、日期相近就建議合併成同一則事件的附加證據（例如發票補上品項），由使用者確認。

## Consequences

- 沒有發票的刷卡照樣完整：通知本身就足以成為一則事件，發票是選配的證據。
- 合併只建議、不自動執行，符合 spec §10「全自動記帳會讓餘額飄掉」。
- 每個來源都要保留原文與來源 id，才能去重與日後重新解析。
