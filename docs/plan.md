## 使用者的決定

### 方向

- **形式**：先做 React PWA，再用 Capacitor 包成 APK。理由是使用者自己的：AI 好寫、好維護，自己測試方便。
- **資料放在新的免費 Firebase 專案**，不跟國王日記擠在 `baobu-app`（「不要跟國王日記擠在同一個專案裡」）。國庫和窩日記共用這個專案：同一套登入、同一個資料庫，各自一個網址。
  背景：在 `baobu-app` 開第二個資料庫要升級付費。新 app 跟國王日記是不同的帳號（用同一個 Google 帳號登入）。
- **repo 用 monorepo**：`apps/treasury`（國庫）、`packages/core`（兩個 app 共用的規則）先建；`packages/ui` 用到再建；`apps/nest-diary`（窩日記）開工時才建。每個 app 各自打包。
- **APK 只當殼**：打開時載入網址，畫面與功能改了不用重裝，只有原生的部分（桌面小工具、讀通知、NFC）改了才重裝。上線後也一樣，APK 只連正式網址。
- **一個網址**：現在的網站就是測試的網站，不另開測試網址；正式上線後還要改時，再開測試網址。**上線前要能一鍵重置，上線後不能。**
  什麼時候上線、開始用真實資料，使用者會說，**做到一半不用問**。
- **先測試，做到八九成才正式用**：等寶也搬過來、決定怎麼跟國王日記合併之後才正式開始用。寶搬過來（階段 6）之前只有步在用。
- **共同花費暫時由國王日記管**：國王日記用了一兩年，**最怕弄壞它**；不寫入國王日記。之後合併是把國王日記的資料**複製**過來，國王日記照常運作當備份。國王日記的 bug 在它自己的 repo 修。
- **很久才有東西可以摸沒關係；畫面很重要。** 第一版畫面先乾淨簡單，把功能做對；畫風之後再決定、整個換上去。
- **不做代登入網銀**（存網銀帳密、代登入抓資料）。
- **NFC 讀悠遊卡**：包成 APK 之後再研究，不是「不做」。
- **家務、物品**：先不想，先把記帳做完整。
- **素材**：要用外部素材讓 app 更豐富，挑哪些還沒定。

### 記一筆

- **自動記帳**：付完錢後通知進收件匣，**按一下確認**就入帳。不要求完全不碰。
- **快速記一筆**：必填的只有金額。可以選罐子、標籤，記一個簡單的名稱（怕之後補記時忘記是什麼）。
  快速記要出現在**桌面小工具**，而且**可以用說的**；用說的時，希望 app 了解自己，自動記好、分好標籤。
- **平常只記誰出、幫誰**：「我覺得只要記誰(寶步)幫誰(寶步共)出就好，寶媽／朋友都不用……要不要還這個不用填，預設都是要還，平常也不常寵對方，所以可以放在進階寫不用還」。
  兩人住一起，常幫對方付，**不要求馬上還**，先記著，之後共同花費多出一點或偶爾幫對方出就抵掉。比例不是一半（例如愛珍食 6:4）很少見，放進階。
- **誰記都可以，一筆只記一次**（國王日記裡步也幫寶記寶付的）。
- **對方記了「幫我付」或「幫共付」，我這邊也看得到；「幫自己付」的對方看不到。**
- **單獨選的只有帳戶、罐子、誰出、幫誰，其他都是標籤。** 標籤可以多選，想多記一點資訊時就多點幾個；怕標籤太多不好選。
- **三個幫手**：常用的排前面、可以長按拖曳換位置；打同樣的名稱就帶出上次用的標籤；名稱自動補完。
- **一筆可以拆成好幾個品項**，每一項可以有不同的罐子與標籤。
- **退款**：在原來那筆上作註記。
- **刷寶媽卡要記得起來**：之後要看得到總共刷寶媽卡多少、某段時間刷多少、某段時間日常和冥想各刷多少。
  寶媽卡是寶學生時期媽媽給的信用卡，帳單由寶媽繳；寶現在平常用自己的卡，偶爾才刷（大筆的例如冥想），偶爾會還寶媽一次 5,000 左右。
- **幫朋友先付（朋友之後還我）、寶媽這類平常用不到的，不要出現在平常記帳的畫面**，放進階；跟朋友平分要能一鍵算好。**不要讓任何數字被灌水。**
- **外幣**：要做，當成出國玩時用的特殊功能。要記得到：誰拿多少台幣換了多少外幣、最後剩多少外幣、換回多少台幣。

### 帳戶

- **帳戶總覽用卡片牆**（樣板 B）：視覺化又清楚；常用的（例如錢包）要能放上面，長按拖曳調整位置。
- **帳戶可以自己取名字、寫備註**（例如這個拿來存款、這個領薪水、這個存玩樂的錢）。之後可能有好幾張信用卡。
- **帳戶先預設好**：AI 把帳戶問清楚，app 一開始就預設好，之後可以新增、刪減。帳戶資料使用者方便時再填，放不公開的 `.local`，不進公開 repo。
- **加密貨幣**：步和寶一起投資，錢放在同一個幣安和冷錢包（合成一個帳戶），分不出誰是誰的；只在意各自投入多少、之後拿出來多少，不在意市值。之後可能個別投資。
- **押金**：付的時候當支出，退回來當收入（「就算我意外的收入的感覺」）。
- 目前**沒有共同的日常花用的錢**（共同帳戶、共同錢包都沒有）。借錢給別人目前沒有，之後再想。

### 罐子與看統計

- **用「六個罐子」的概念分預算**，罐子可以新增。步先放日常、玩玩、財富自由；寶用日常、玩玩、冥想。比例自己可以調。分太多會覺得雜。
- **罐子要呈現「花在誰身上」**：「統計花費或是看那邊要能夠呈現寶在冥想這邊花多少，不論是自己出，我寵寶還是刷寶媽卡」。
- **每個數字都要能用不同視角拆開看**：「冥想罐可以看到固定支出，自己付的，被寵的，分期的……其他地方也是」。平常預設看一種，想分析時再切換。
- **還款也要能看到拆開的樣子**（例如冥想 3,000 裡寶媽還沒收回多少、寶自己還了多少）。
- **分期、年繳按月攤**，統計才不會某個月特別爆掉（「之後可以再想想完善」）。
- **「我付的」和「我用的」**：我付的 < 我用的，代表對方出比較多；我付的 > 我用的，代表我幫對方出比較多。
- **記帳要回答問題，不只是流水帳**：國王日記的統計只讓人覺得「喔，然後呢」。使用者覺得有用的問題：
  這個月罐子還能花多少、照這速度月底會不會超過；這個月哪裡特別多花；錢這半年變多還是變少；固定花費扣掉後剩多少真的能花；
  少吃幾次高級吃吃一年能多存多少；大筆花費前要存多久；離發薪日每天還能花多少；年度回顧（冥想、捐款、玩玩各花多少）；
  記帳準不準（對帳差額）；往來帳變多還是變少；某段時間我幫我出、我幫對方出、對方幫我出各多少；常買的東西**物價變化**。
- **目標罐子**（之後做）：設幾個目標、把錢存進去，遊戲化、好玩，有動力完成。
- **首頁**（放什麼之後再決定）：可以放幾張答案卡片；也想過做成像記帳城市那樣有趣的互動，或可以互動的背景（例如一起養狗狗貓貓）。
  不要一進 app 就是一堆資訊，希望有遊戲感、互動感、沉浸感。

## 已討論、使用者沒有反對的理解

AI 提的、使用者答「好」「照建議」「可以」的。錢的名詞以 GLOSSARY 為準。

### 錢怎麼算

- **三個數字**：**我用的**看「幫誰」（幫自己的＋幫共的自己那一份，不管誰出、要不要還；罐子、標籤的統計都用它）；
  **我付的**看「誰出」（從自己帳戶出去的支出）；**往來帳**是誰出和幫誰不同、要還的部分累積下來的數字。
  所以「寶的冥想 3,000」不管寶自己付、步寵寶、還是刷寶媽卡，寶的冥想罐都是 3,000，寶自己的錢只在寶自己付時才少。
- **視角**：每個數字都能依誰出、帳戶、要不要還、罐子、標籤、固定花費、分期拆開；平常只顯示總數，點一下才展開。
- **一筆錢的種類**：支出、收入、轉帳、還款、對帳差額；退款沖回原本那一項。「支出」只說種類，不當統計數字。
- **轉帳**（自己或共有的帳戶之間）、**還款**、**對帳差額**都不算支出也不算收入。刷信用卡當下就是支出，繳卡費是轉帳。
- **還款**：把之前別人幫自己出、要還的錢還回去（寶還步、步還寶、寶還寶媽、朋友還自己）。不綁品項，**先抵最早還沒還清的**，進階可以手動指定，所以看得到每一筆已還多少、還欠多少。
- **寶媽卡**：是一個帳戶，記帳時選它就知道是寶媽出的（誰出照樣記寶）。刷寶媽卡算在寶的罐子（我用的），不算寶的我付的；
  帳戶上累計寶媽幫出、寶還了、還欠多少，不算進寶的淨資產。還寶媽是還款。
- **進階**（平常看不到）：不用還（寵對方）、比例不是 5:5、某一個品項幫別人、有人要還我（待收，可一鍵平分，除不盡的 1 元算自己）、按月攤、手動指定還款抵哪一筆。
- **寵對方**：自己出、幫對方、不用還，往來帳不動；買東西給對方算對方的我用的，直接給錢算對方的收入。對方那邊叫**被寵**。
- **幫朋友先付**：「有人要還我」記成待收，我用的只算自己的份；朋友怎麼還都記還款。
- **按月攤**：分期或年繳，帳戶在付錢那天記全額，我用的與罐子按月平均攤。
- **回饋、點數、折抵**：結帳折抵記實際付的；之後回饋記收入、標籤「回饋」；點數不當錢記。
- **加密貨幣**：一個步和寶共有的投資帳戶，轉進去是轉帳；記步、寶各投入多少，不記市值；之後個別投資再開自己的投資帳戶。
  之後做預算時，轉進投資帳戶的錢可以算成撥進財富自由罐。
- **學貸、保險**是固定花費（年繳就按月攤）。**押金**付的時候記支出加標籤「押金」（看統計時可以排除；這個標籤先不預設，要用再加，使用者 2026-10-31），退回記收入。
- **對帳**：看著實際餘額輸入，跟算出來的比；差額叫對帳差額，另外列。每個帳戶的第一次對帳就是初始餘額。
- **金額**：整數（台幣就是元）。**日期**一律記消費當天。

### 記一筆的細節

- **帳戶**：銀行、現金、儲值（悠遊卡、iCash Pay 儲值金）、信用卡（每張一個帳戶，餘額是欠的）、投資。屬於一個人，或兩人共有。
  LINE Pay、全支付、iCash Pay 綁卡這類是**付款方式**，是普通的標籤，可記可不記；錢從背後的帳戶出去。
- **品項**：整筆有時間、帳戶、誰出、幫誰（預設）、整筆的標籤（自動套到每一項）；每一項有名稱、金額、罐子、標籤。
- **預設值**：帳戶預設上次用的（第一次預設現金）、時間預設現在、幫誰預設跟上一次一樣、要還；沒選罐子算日常；標籤可以帶預設罐子（使用者 2026-10-31：高級吃吃不用帶玩玩，預設的標籤都不帶）；標籤可以先空著，空的集中提醒補。
- **舊分類搬過來**：刷寶媽卡 → 帳戶；玩玩 → 罐子；寵寶寶、寵步步 → 進階的「不用還」；其他 → 標籤。「家樂福/全聯」拆成兩個標籤，「蝦皮/光南」綁在一起（使用者 2026-10-31）。
  寶的「幫共付」罐子不需要了（幫共是「幫誰」的一種），等寶搬過來時再跟寶確認一次。
- **誰記都可以**：對方自動看到跟自己有關的，看到的人只能標「有疑問」，不能改對方的紀錄。
  一筆裡同時有幫自己、幫對方的品項時，對方看得到**整筆**（例如家樂福 820 裡 650 幫寶、170 自己的零食，寶看得到整張；使用者選的）。
- **幫對方記時選得到對方的帳戶**（2026-10-31，使用者答「照建議改」）：誰出選寶時列出寶的帳戶（含寶媽卡），也可以留空表示不知道。所以對方帳戶的名字、種類互相看得到；餘額看不到（卡片牆只顯示自己的帳戶），備註只有自己看得到。寶搬過來之前，步可以幫寶建帳戶。
- **收入**：只記金額、進哪個帳戶、標籤（薪水、獎金、紅包、回饋…），不分罐子；分配到罐子等階段 7。
- **固定花費**：設定一次（名稱、大約金額、每月幾號、帳戶、標籤），到期**不自動入帳**，出現在收件匣按一下確認，金額不同就改；自動帶「固定花費」標籤。
- **快速記**：PWA 階段是主畫面圖示長按跳出「記一筆」、畫面上有麥克風；用說的時拆好金額、名稱、標籤後先給使用者看一眼，按一下才存。
- **通知**：自己帳戶之間轉帳的兩則通知（出帳＋入帳）是同一筆轉帳；跨行手續費的差額是一筆支出。刷卡通知和之後的出帳通知是同一筆，後到的合併。
- **外幣**（之後做）：外幣現金是一個有幣別的帳戶，換匯是轉帳，在國外花掉外幣才是支出。

### 畫面

- 帳戶卡片第一次依「最常用的在上面」自動排，拖過之後照使用者排的；太久沒對帳的卡片寫出天數。
- 記帳要回答的問題分三層：首頁幾張答案卡片、「問問題」頁（一排預設題目，app 自己算，不用 AI）、遊戲化之後再做。

### APK 與網址

- 第 2 階段結束時包第一個 APK（殼＋桌面小工具，一按跳到記一筆）；第 5 階段加讀通知。
- 上線後改動先在測試網址試過，沒問題才更新正式網址。真的遇到離線不夠用時，再改成內容打包在 APK 裡（只差一個設定、重裝一次，所以不寫 ADR）。
- 殼＋網址的限制：剛裝好、還沒開過時沒網路打不開；第一次打開慢一點；網頁要用 APK 新加的原生功能時，要先檢查 APK 版本，太舊就提醒更新；不能上架 Google Play（本來就不上架）。

### 怎麼蓋

- 從零開始蓋靠：GLOSSARY 與 plan.md、`packages/core` 的介面用 `codebase-design`（設計兩次）、算錢的規則用 `tdd`、每一輪 `kickoff` → `matt-code-review`、難回頭的決定寫 ADR。
- `graphify` 等階段 1 做完（有真的程式碼）才第一次跑，之後每個階段結束時 `--update`；第一次跑之前先把 Python 套件 `graphifyy` 升到最新版。
